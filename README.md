# Spotify-Music-Analysis-Dashboard-TABLEAU
This project presents an interactive Spotify Music Analysis Dashboard developed using Tableau. The dashboard provides insights into Spotify music data through visual analytics, helping users understand music trends, artist popularity, genre performance, and audio feature relationships.

## Problem Statement

Music streaming platforms generate massive amounts of data containing information about artists, genres, track popularity, and audio features. Analyzing these datasets manually is difficult and time-consuming.

This project aims to build an interactive Tableau dashboard that helps users identify popular genres, top-performing artists, overall music popularity trends, and relationships between audio features such as Energy and Danceability.

## Objectives
Analyze Spotify music dataset.
Identify top-performing artists and genres.
Measure overall track popularity.
Explore the relationship between Energy and Danceability.
Provide interactive filtering for data exploration.

## Dataset Information

Dataset Source: Spotify Music Dataset

Records: 89,741 Tracks

Key Fields:
- Track Name
- Artist Name
- Genre
- Popularity
- Danceability
- Energy
- Acousticness
- Loudness
- Tempo

## Key Insights
1. Popular music genres were identified based on average popularity scores.
2. Top artists were ranked according to average popularity.
3. Energy and Danceability showed noticeable relationships across tracks.
4. Interactive filters allow users to perform detailed analysis.
